読み取った明細（参考。保存はされません）

    最初に GAS の URL と合言葉（トークン）を設定してください。

    設定はこの端末のこのアプリの中にだけ保存されます。ホーム画面から開いたアプリと Safari は保存先が別なので、 ホーム画面に追加したあとは、アプリを開いてから設定してください。

    カード番号・会員番号・氏名・電話番号・バーコードなど、送りたくない部分を指でなぞって囲むと、黒く塗りつぶします。 少し広めに囲んでください。

    塗りつぶした画像を縮小して、Google の Gemini API（無料枠）に送ります。元の写真は送りません。 無料枠に送った内容は Google の製品改善に使われ、人が確認する場合があります。
